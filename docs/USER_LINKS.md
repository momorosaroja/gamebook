# Anwenderdokumentation — Links (links.php)

Zweck
- Erstellen, Bearbeiten, Filtern, Kopieren und Löschen von Links zwischen Orten, Choices und Pages.

Wichtige Aktionen
- Neuen Link anlegen: Wähle Place, optional Choice und Page, klicke "Hinzufügen".
- Link bearbeiten: Klicke auf "Bearbeiten", passe Place/Choice/Page an, füge Skill-Ranges oder Objects hinzu, speichere.
- Link kopieren: Klick auf "Kopieren" erstellt eine vollständige Kopie inklusive `link_objects` und `decision_links`.
- Löschen: Klick auf "Löschen" löscht Link und alle zugehörigen Objekte (Bestätigung erscheint).

Filter & Sortierung
- Nutze das Filter-Formular um Links nach Place, Decision, Skill oder Object einzuschränken.
- Sortierung über Dropdown (z. B. nach `last_date`).

Hinweise
- Beim Bearbeiten kannst du Skill-Ranges angeben (`von` / `bis`) und einzelne Objects hinzufügen.
- Größere Änderungen könnten Auswirkungen auf die Generierung haben — Backup vor Bulk-Operationen.
