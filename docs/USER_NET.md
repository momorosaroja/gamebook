# Anwenderdokumentation — Net (net.php)

Zweck
- Grafische Darstellung des Netzwerks (Orte und Wege). Erlaubt Anzeige von Subnetzwerken.

Benutzung
- Öffne die Seite; das Hauptnetzwerk wird angezeigt.
- Wenn Subnetzwerke vorhanden, klicke auf "Subnetzwerk anzeigen" neben einem Ort, um tiefer zu zoomen.

Hinweise
- Interaktive Darstellung; Elemente können verschoben werden (je nach vis-network Einstellungen).
- Bei großen Netzwerken kann das Rendering länger dauern.
