# Anwenderdokumentation — Places (places.php)

Zweck
- Orte mit optionaler Parent-Hierarchie und Rich-Text-Feldern verwalten.

Wie nutzen
- Neuen Ort anlegen: Formular im Abschnitt "Neuen Ort anlegen" ausfüllen und speichern.
- Bestehenden Ort bearbeiten: Wähle einen Ort, ändere Felder, Speichern.
- Löschen: Wähle Ort, klick "Ort löschen" (nur möglich, wenn keine restriktiven Referenzen bestehen).

Hinweise
- Textfelder (text1..text5) sind optional und können für Szenen, Beschreibungen oder Variationen genutzt werden.
