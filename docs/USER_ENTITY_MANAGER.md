# Anwenderdokumentation — Entity Manager (entity_manager.php)

Zweck
- Verwaltung der Lookup-Listen: `skills`, `objects`, `characters`.

Benutzung
- Wähle oben die zu bearbeitende Tabelle (Skills/Objects/Characters).
- Neue Einträge: Name eingeben → Speichern.
- Bestehende Einträge: Name ändern und auf "Ändern" klicken.
- Löschen: Klick auf "Löschen" neben dem Eintrag (es erscheint eine Bestätigung).

Hinweise
- Änderungen wirken sich auf das Spiel/Generator aus. Mache Backups vor größeren Anpassungen.

Datum: 2026-08-02
