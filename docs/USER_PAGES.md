# Anwenderdokumentation — Pages (pages.php)

Zweck
- Seiteninhalte bearbeiten und verwalten.

Wie benutzen
- Klicke in der Liste auf eine Seite (Spalte "Text"), um sie zu öffnen.
- Bearbeite das Feld "Seiteninhalt" und optional "Kommentare", dann klicke auf "Speichern".
- Löschen: Wenn eine Seite keine Links referenziert, erscheint ein Löschen-Button; klick und bestätige.

Hinweise
- Seite kann nur gelöscht werden, wenn keine Links existieren.
- Nutze Vorschau/Backup vor großen Änderungen.
